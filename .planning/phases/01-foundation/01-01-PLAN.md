## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| repo → CI runner | GitHub Actions executes repo scripts with repo secrets; a malicious dependency or script could exfiltrate secrets |
| build-time config → runtime | env vars validated at module load; a missing/wrong var should fail fast, not silently misconfigure |
| developer → AI build tooling | pasting customer data into Claude Code/Cursor is an exfiltration vector (no customer data exists yet, but the lesson is seeded now) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-1-01 | Information Disclosure | `.env.local` / secrets committed to git | mitigate | `.gitignore` keeps `.env*` (except `.env.example`); `.env.example` has placeholders only; CI never echoes secrets |
| T-1-02 | Tampering (config) | hardcoded site URL slips in, breaks the trochia.ai migration / leaks wrong host | mitigate | all URLs from `lib/env.ts`; ESLint `no-restricted-syntax` rule against literal `https://trochia` URLs; Code Reviewer backstop |
| T-1-03 | Elevation of Privilege | a file outside `ai/**` imports the Anthropic/OpenAI SDK directly, bypassing the chokepoint (and prompt-caching / cost controls / Langfuse tracing) | mitigate | ESLint import-boundary rule bans `@anthropic-ai/sdk` and `openai` imports outside `src/ai/**` (no-ops until `ai/` exists in Plan 04, then enforced) |
| T-1-04 | Information Disclosure | financial figures / PII logged to console → Sentry/Amplitude | mitigate | redacting `lib/logger.ts` + ESLint `no-console` ban in `src/**`; sensitive-field redaction (small list now, grows) |
| T-1-05 | Repudiation / Info Disclosure | customer data pasted into AI build tooling for debugging | accept (process control) | `tasks/lessons.md` seeded with the synthetic-fixtures-only rule; reinforced in CLAUDE.md; no customer data exists in Phase 1 anyway |
