### Type-scale rationale / guardrail exception (per-typeface)

**Design System Exception — documented and approved.** The standard UI quality guardrail of "≤4 font sizes, ≤2 font weights" is a *global* structural heuristic. Trochia's brand system is a deliberate **3-typeface architecture** mandated upstream by `docs/BRAND.md` and `docs/DESIGN-REFERENCE.md` (Geist for display/headings, Inter for body/UI, Geist Mono for numerics/code). For a multi-typeface system, the guardrail is correctly interpreted **per typeface, not globally** — each family must independently stay at or under 4 sizes and 2 weights. It does:

| Typeface | Role | Sizes | Weights | Holds? |
|----------|------|-------|---------|--------|
| **Geist** | Display + headings | 4: `text-display` (~4rem), `text-h2` (~2.5rem), `text-h3` (~1.625rem), `text-h4` (~1.25rem) | 2: 600 (headings) / 700 (display emphasis, e.g. wordmark) | ✓ ≤4 sizes, ≤2 weights |
| **Inter** | Body + UI | 3: `text-body` (~1.0625rem), `text-body-sm` (~0.9375rem), `text-label` (~0.8125rem) | 2: 400 (body) / 500 (emphasis, labels) | ✓ ≤4 sizes, ≤2 weights |
| **Geist Mono** | Numerics + code | 2: `text-mono` (`text-base`), `text-mono-sm` (`text-sm`) — Tailwind-native size utilities, **not** custom `fontSize` keys | 1: 400 | ✓ ≤4 sizes, ≤2 weights |

> **Note on the Tailwind config.** `tailwind.config.ts` defines **7 custom `fontSize` keys** — `display`, `h2`, `h3`, `h4`, `body`, `body-sm`, `label` — because those keys span the **two** typeface roles Geist (4) + Inter (3). That total is *expected and correct*; it is not 7 sizes "in one typeface." The mono roles deliberately do **not** add custom `fontSize` keys: `text-mono` / `text-mono-sm` are composed from Tailwind's native `text-base` / `text-sm` with `font-mono`. Per typeface the contract holds. No token values change as a result of this exception — this subsection is justification, not a re-spec.

## Color

Tokens (from BRAND.md / DESIGN-REFERENCE.md — use these exact Tailwind token names):

| Role | Token | Value | Usage |
|------|-------|-------|-------|
| Dominant (~60%) | `paper` | `#FAFAF7` | Page background, the default surface. Warm off-white — never `#FFF`. |
| Text + structural (~30%) | `ink` | `#0A0E1A` | Primary text, primary-button background, mark color. Cool near-black — never `#000`. |
| Secondary text / muted UI | `graphite` | `#6B7280` | Secondary copy, muted labels, "AI" suffix in long-form wordmark, disabled nav |
| Borders / soft surfaces | `stone` | `#ECEAE3` | 1px hairline borders, dividers, soft fills, active nav-item background |
| Accent (~10%) | `signal` | `#F25C2A` | THE single accent. **One moment per surface.** See reserved list below. |
| Success | `success` | `#0F9D58` | Positive states, checkmarks in pricing feature lists |
| Warning | `warning` | `#E5A100` | Caution states |
| Destructive | `danger` | `#E53935` | Errors, destructive actions, input error borders/helper text |

**Accent (`signal`) reserved for, and ONLY for:**
- The mark's signal node (the dot)
- The eyebrow text on the hero (`text-label text-signal`)
- ONE call-to-action per surface — either a `bg-signal` button or a `text-signal` link accent, never both on the same surface
- The mono step numbers in "How it works" (`01 02 03 04` in `text-mono text-signal`)
- The pricing "Most chosen" featured-card border (`border-2 border-signal`) + its badge
- Pull-quote left-border bar on `/manifesto` (4px Signal)
- Link hover color (`hover:text-signal`)
- The hero live-element illumination accent (Ink → Signal step transition)

Never: body text, large fills, multiple accents on one surface, gradients (except the optional Ink→Ink/0 fade in the hero live element), section background tints.

**Shadow rule:** No shadows on cards — use 1px `stone` borders. Only modals/dropdowns may use a single low-opacity Ink shadow: `0 8px 24px rgba(10,14,26,0.08)`.

**Border rule:** Always 1px. `border-stone` at rest; `border-ink/20` (or `/30`) on hover for interactive elements. Radii: `rounded-xl` (12px) cards, `rounded-lg` (8px) buttons + inputs, `rounded-full` pills/badges/avatars.

## Copywriting Contract

Voice: **operator, not assistant.** Direct, founder-grade, short sentences, concrete nouns, verbs that move. No emoji in product copy. No "AI buddy" tone. Trochia *drafts / matches / briefs / scores / tracks* — it does not *feel / love / want / help*. Never the strings "rolling fund", "investment advice", "legal advice" (without a "not"/"this is not" prefix), "fund", "investment vehicle", "adviser" — banned-string CI check runs from this phase.

## Motion Contract

| Motion | Duration | Easing | Use |
|--------|----------|--------|-----|
| Hover transitions | 120ms | `ease-out` | Color, border, background |
| Press state | instant | — | `active:scale-[0.98]` on buttons only — no other physics |
| Page enter | 200ms | `ease-out` | Fade-up: `translateY(8px→0)` + `opacity(0→1)` |
| Scroll reveal | 300ms | `ease-out` | Same as page enter, on viewport intersection |
| Modal / Sheet enter | 250ms | `ease-out` | Fade + slight upward translate |
| Hero live-element loop | 800ms/step | `ease-in-out` | Sequential Ink→Signal illumination, 2s pause at loop end |

**Reduced motion:** respect `prefers-reduced-motion: reduce` — all non-essential motion off; hero live element → static composition. This is a Phase-1 exit-gate item.

**Framer Motion:** used sparingly (hero timeline, page/scroll reveals). Not for decoration.

## Anti-Patterns — DO NOT (all banned; Code Reviewer rejects PRs introducing these)

- ❌ Gradient backgrounds on full sections (reads cheap, ages fast) — only exception: optional Ink→Ink/0 fade inside the hero live element
- ❌ Glassmorphism / frosted-glass surfaces
- ❌ Cursor-following gradient spotlights / spotlight-follows-mouse effects
- ❌ Multiple competing accent colors — Signal is the only accent, one moment per surface
- ❌ Centered hero text on desktop — Trochia heroes are **left-aligned**
- ❌ Stock illustrations (3D characters, abstract waves, laptop/phone-with-screen art) — show the mark, real product screenshots, or code/output, never metaphor
- ❌ Carousels / auto-rotating banners / auto-playing background video / marquee tickers (a very slow logo strip is the only marquee-ish exception)
- ❌ Confetti / sparkles / particle systems / spring physics / bounces on any state
- ❌ Drop shadows on cards — use 1px `stone` borders; shadows only on modals/dropdowns at the one specified low-opacity value
- ❌ Scale-on-hover beyond the `0.98` press state
- ❌ Background gradient animations
- ❌ "AI buddy" copy ("Hi! I'm Trochia 👋"), emoji in product copy, anthropomorphic verbs (Trochia "feels"/"loves"/"wants"/"helps")
- ❌ "Trusted by" + logos with no real relationship — placeholder copy must be honest about being placeholder
- ❌ Any Tailwind color or font outside the brand token system
- ❌ A 5th custom `fontSize` key inside a *single* typeface role (the 7 total config keys span Geist + Inter — that is the documented per-typeface exception, not a license to expand any one family beyond 4)
- ❌ Bare generic CTA labels — "Cancel", "OK", "Submit", "Save", "Yes", "No", "Send", "Close" as a standalone button label. Every button carries a specific verb+noun ("Delete account", "Keep my account", "Start your raise", "Keep editing", "Send outreach", "Keep draft"). The founder-approval Dialog's primary action is always the noun-bearing `Send {thing}` form — never bare "Send". Dismiss buttons in destructive/confirmation/modal Dialogs use the "Keep {noun}" convention — never bare "Cancel"/"Close".
- ❌ The banned compliance strings: "rolling fund", "investment advice", "legal advice" (without "not"/"this is not"), "fund", "investment vehicle", "adviser"
- ❌ Hardcoded site URL anywhere — always `process.env.NEXT_PUBLIC_SITE_URL` / `NEXT_PUBLIC_APP_URL`
- ❌ Autonomous external sends — every email/intro/signature/payment goes through the founder-approval Dialog
- ❌ Pure `#000` or pure `#FFF` — use `ink` (`#0A0E1A`) and `paper` (`#FAFAF7`)
- ❌ A `xs` button size (small buttons read as a toy)
- ❌ `huashu-design` (banned for Trochia — commercial-license violation)
