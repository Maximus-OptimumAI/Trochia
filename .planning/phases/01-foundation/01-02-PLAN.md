## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| third-party shadcn registry → repo | `npx shadcn add` pulls component source into the repo; UI-SPEC limits this to the official registry only |
| UI component → external action | the founder-approval Dialog is the only sanctioned path for anything that leaves Trochia (XC-02); a one-click send component would bypass it |
| design tokens → arbitrary CSS | a Tailwind color/font outside the token system breaks the brand contract and the Code-Reviewer gate |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
