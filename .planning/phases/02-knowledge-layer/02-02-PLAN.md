    Export shapes:
    1. `provenanceFieldSchema` — `{ source_snippet: string (min 1, max 800), confidence: number 0..1, extracted_at: ISO datetime string, last_updated: ISO datetime string, snooze_until: ISO datetime string | null }`. Use `z.iso.datetime()` (or `z.string().datetime()` per context7 lookup).

    3. `teamSchema` — `z.object({ founders: z.array(...).optional(), advisors: z.array(...).optional() }).catchall(z.unknown())`. Each founder: `{ name, role, background?, equity_pct? }`. Permissive on extra keys (per CONTEXT decision: jsonb shape can evolve at app layer without migrations).
    4. `tractionSchema` — `z.object({ mrr, arr, customers, growth, runway, ... }).catchall(z.unknown())`. All numeric metrics are `z.number().optional()`; currency expressed via a sibling `currency: z.string().length(3).optional()` (ISO 4217). Mixed-currency MRR/ARR is handled at app layer; the schema accepts both.
    5. `narrativeSchema` — `z.object({ problem: z.string().optional(), solution: z.string().optional(), why_now: z.string().optional(), why_us: z.string().optional() }).catchall(z.unknown())`.
    6. `businessMemoryDraftSchema` — top-level draft (what the EXTRACTOR returns):
       ```
       z.object({
         companyName, oneLiner, sector, stage, geography, incorporationStatus    // all .string().optional()
         foundingDate                                                            // z.iso.datetime().optional()
         team: teamSchema.optional(),
         traction: tractionSchema.optional(),
         narrative: narrativeSchema.optional(),
         provenance: provenanceSchema,                                           // REQUIRED — extractor must emit
       })
       ```
       Drop the lifecycle timestamp columns (`extractedAt`, `confirmedAt`, `lastUpdatedAt`, `createdAt`, `updatedAt`) — those are server-set on persist, not extractor output.
    7. `businessMemoryConfirmedSchema` — extends `businessMemoryDraftSchema` with `confirmedAt: z.iso.datetime()`. This is the shape the confirmation form submits.
    8. Inferred TS types: `export type BusinessMemoryDraft = z.infer<typeof businessMemoryDraftSchema>` + `BusinessMemoryConfirmed`.
    9. A tiny invariant guard (helper function `assertProvenanceCoversFields(draft)`) that returns the count of populated top-level scalar fields and the count of provenance keys that match them — the unit test uses this to assert ≥8 fields populated + ≥3 with source_snippet.
